# ✨ Functional Magic: Conjure Code, Weave Wonders ✨

In the arcane halls of wizardry, some mages rely on instinct, improvising spells with reckless abandon. But not you. No, you are a scholar of the arcane, a master of precise incantations. You believe in deterministic magic—spells that always resolve the same way, every time. 

Welcome to **Functional Magic**, a Haskell-inspired language designed to **describe and "cast" spells with mathematical elegance**. Whether you're a wizard seeking to rewrite the very laws of magic or a developer indulging in some arcane programming, this is the language that turns spells into structured logic.

Prepare your spellbooks. The compiler awaits.

# What?
Some wizards like to make sure their magic always casts in the same way every time. These mages are here to get shit done. Progress their world. This is the language they use to communitcate and cast their magics.

# No seriously, What is this?
A haskell style language for describing and "casting" spells.

# *Why* does this exist?
While playing DND 5e with some friends I wanted to create a wizard that wanted to "re-write" magic. As a software developer it was a nice amount of self insersion into the character. After which I thought 'why don't we write a compiler for these "spells"' and here we are.

> [!NOTE]
> There will be mistakes here, I'm not super well read into the dnd 5e rule set and functional programming is completely new to me.

We will be basing most of the work off [Write You a Haskell](https://smunix.github.io/dev.stephendiehl.com/fun/WYAH.pdf). Which can also be found in [this repo](https://github.com/sdiehl/write-you-a-haskell).
